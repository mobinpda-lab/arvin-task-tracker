# آروین

نرم‌افزار فارسی مدیریت یادداشت‌ها، کارها و ثبت پیگیری‌ها.

## نسخه 0.3
- انتخاب تاریخ هجری شمسی از همان ابتدا
- یادداشت و کار پیگیری‌دار
- پیگیری با شرح اختیاری، تاریخ/ساعت قابل ویرایش و یادآوری
- دسته‌بندی، تگ، چک‌لیست، بایگانی و سطل زباله
- جستجو و فیلتر دسته‌بندی در صفحه اصلی
- مرتب‌سازی بر اساس آخرین تغییر، تاریخ و عنوان
- Swipe قابل تنظیم
- انتخاب چندتایی با مکث و انتقال به دسته یا سطل زباله
- PDF و اشتراک‌گذاری
- پشتیبان خودکار محلی، دستی و بازیابی
- فونت پیش‌فرض Vazirmatn
- ذخیره خودکار بعد از تغییرات و قبل از بازگشت

> اتصال مستقیم OAuth به Dropbox و فونت Faraz هنوز نیاز به مرحله اتصال/آپلود اختصاصی دارد؛ نسخه فعلی ارسال فایل پشتیبان به Dropbox را از طریق Share سیستم پشتیبانی می‌کند.
